# CyberMind
--
CyberMind is an interactive web-based quizez platform specialized in cybersecurity. It aims to assess and evaluate users' security knowledge through carefully designed technical challenges and quizzes, while providing dedicated role-based views for both students and instructors.

## 🚀 Features
--
Role-Based Views:

Student View: To take quizzes, complete challenges, and view instant performance feedback.

Instructor View: To manage questions, quizzes, and track student progress.

Interactive Quiz System: Diverse questions and challenges covering various cybersecurity concepts.

Database Management: Securely and efficiently stores user data, questions, and grades.

## 🛠️ Tech Stack
--
Frontend: HTML, CSS, JavaScript (for building responsive and interactive user interfaces).

Backend: PHP (for handling server-side logic, authentication, and database operations).

Database & Management: MySQL for structuring and managing relational tables for users, questions, and results.
